🗳️ Enquête Femmes et Souveraineté
Analyse des Correspondances Multiples des opinions et positions

Contexte : Cette application présente les résultats d'une Analyse des Correspondances Multiples (ACM) réalisée à partir d'une enquête portant sur les femmes et la souveraineté.

📊 Objectifs

  • Visualiser la distribution des individus selon leurs opinions
  • Identifier les profils types et les positions moyennes (centroïdes)
  • Explorer les relations entre variables catégorielles

📁 Données

Le fichier femmescoordonnees_methode_tirage.csv contient :

  • Les coordonnées factorielles : Dim1, Dim2, Dim3
  • Des variables catégorielles : genre, vote, opinions, etc.

📋 Navigation

  • Individus : Visualisation des individus colorés selon une variable (2D/3D)
  • Centroïdes : Graphique factoriel des centroïdes avec sélection (2D/3D)
  • Bibliographie : Références académiques
💡 Astuce : Utilisez les onglets en haut pour explorer les données. Les modes 2D et 3D sont disponibles pour les visualisations.
